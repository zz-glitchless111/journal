# level 23->24
## Learned
- `shopt -s nullglob` - if no files match, bash returns an empty list.
- `whoami` - username
- `for i in * .*` loops over files in directory
- `if ["$i" != "."] && ["$i" != ".."];` ignores two directory entries, current directory and parentdirectory
  - so only processes real files, not directories
- `owner ="$(stat --format "%U" "./$i")"`
  - runs `stat` on the file, which shows detailed metadata about a file
  - `%U` means get username of file owner
- `if "${owner}"  "bandit23"] && [-f "$i"]; then`
  - owned by bandit23, and is a file.
- `timeout -s 9 60 "./$i"`
  - runs for 60 seconds, if exceeds time kill with `-s 9` (SIGKILL)
    - immediately terminated by OS
- `rm -rf "./$i"` removes after processing.
  - `-rf` for recursive and forces it (no prompts)
- `#!/bin/bash` makes it run the file using bash
  - `chmod +x myscript.sh` adds execute permission
## Commands
```bash
cat /etc/cron.d/*
cat /usr/bin/cronjob_bandit24.sh
nano /var/spool/bandit24/foo/myscript.sh
 #!/bin/bash
 cat /tmp/bandit_pass/bandit24 > /tmp/mypassword
```
